# 💰 Calculadora de Presupuesto Personal

Este proyecto es una herramienta web interactiva diseñada para ayudar a los usuarios a gestionar sus finanzas mensuales de manera visual y eficiente. Desarrollado como parte de mi formación académica en Ingeniería de Software.

## 🚀 Características Principales
- **Gestión bajo POO:** Lógica de negocio estructurada mediante clases en JavaScript para un código limpio y mantenible.
- **Visualización de Datos:** Integración de **Chart.js** para mostrar la distribución de ingresos y gastos en tiempo real.
- **Diseño Responsivo:** Interfaz adaptada para un funcionamiento fluido tanto en dispositivos móviles como en escritorio.
- **Normalización Temporal:** Capacidad de ingresar montos semanales, mensuales o anuales con conversión automática a base mensual.

## 🛠️ Tecnologías Utilizadas
- **HTML5 & CSS3** (Uso de Flexbox y CSS Grid para el layout responsivo).
- **JavaScript (ES6+)** (Manipulación dinámica del DOM y lógica de objetos).
- **Chart.js** (Librería externa para gráficos estadísticos).
